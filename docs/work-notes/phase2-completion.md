## 개선 사항

### collection.py
- 작업 ID 및 카테고리 ID 축약 표시 (가독성 향상)
- 날짜/시간 포맷팅 개선
- 진행 중인 작업 개수 표시

### visualization.py
- 브랜드별 집계 기능 추가
  - 브랜드별 평균 가격/랭킹 계산
  - 브랜드별 상품 수 집계
- 상품별 모드에서 사용 불가능한 축 필터링
  - "상품 수" 축은 브랜드별 집계 모드에서만 사용 가능

## 기술 스택

- **웹 프레임워크**: Streamlit 1.28.0+
- **데이터 처리**: Pandas 2.0.0+
- **시각화**: Plotly 5.17.0+
- **데이터베이스**: Supabase (PostgreSQL)

- 모든 페이지는 `shared/services/DataService`를 통해 데이터 접근
- Streamlit의 멀티 페이지 구조 활용 (`pages/` 디렉토리)
- 실시간 업데이트는 polling 방식으로 구현 (향후 Supabase Realtime으로 개선 가능)
- 브랜드 맵의 컨셉/무드/인기도 점수는 Phase 4에서 이미지/텍스트 분석을 통해 계산 예정
